                      蛋糕商城购物车系统 — 实现说明文档
================================================================================

一、项目概述
--------------------------------------------------------------------------------
本项目是一个基于 Spring Boot + 纯前端技术（HTML/CSS/JS）搭建的简单蛋糕商城购物
车系统。用户进入首页可浏览所有蛋糕商品，点击"加入购物车"按钮将商品加入购物车，
在购物车面板可查看已选商品及总价，点击"去结算"按钮可生成订单并通过扫描二维码
（前端 Canvas 模拟生成）完成支付，支付成功后自动清空购物车。


二、技术栈
--------------------------------------------------------------------------------
  后端：Spring Boot 2.7.18 + Spring Web (Spring MVC)
  前端：HTML5 + CSS3 + 原生 JavaScript (Fetch API)
  构建：Maven 3.9+
  JDK：1.8 / 23 均兼容
  运行端口：8080

四、后端实现详解
--------------------------------------------------------------------------------

4.1  Maven 项目配置 (pom.xml)
    - 父工程：spring-boot-starter-parent 2.7.18
    - 依赖：spring-boot-starter-web（内置 Tomcat + Spring MVC + Jackson JSON）
    - 构建插件：spring-boot-maven-plugin（支持 spring-boot:run 一键启动）

4.2  数据模型层 (model/)

    Cake.java —— 蛋糕商品实体
    ┌────────────┬──────────┬───────────────────────────┐
    │ 字段        │ 类型      │ 说明                      │
    ├────────────┼──────────┼───────────────────────────┤
    │ id          │ int      │ 商品唯一编号               │
    │ name        │ String   │ 蛋糕名称（如"草莓奶油蛋糕"） │
    │ price       │ double   │ 单价（元）                 │
    │ image       │ String   │ 图片路径（如 /images/cake1.svg）│
    │ description │ String   │ 商品描述文字               │
    └────────────┴──────────┴───────────────────────────┘
    提供无参和有参构造方法、完整 getter/setter。

    CartItem.java —— 购物车条目
    ┌──────────┬────────┬────────────────────────────────┐
    │ 字段      │ 类型    │ 说明                           │
    ├──────────┼────────┼────────────────────────────────┤
    │ cake     │ Cake   │ 关联的蛋糕商品对象                │
    │ quantity │ int    │ 购买数量                         │
    └──────────┴────────┴────────────────────────────────┘
    额外提供 getSubtotal() 方法，返回 cake.price × quantity，
    方便前端直接展示小计金额。

    Order.java —— 订单实体
    ┌──────────┬────────────────┬──────────────────────────────┐
    │ 字段      │ 类型            │ 说明                         │
    ├──────────┼────────────────┼──────────────────────────────┤
    │ orderId  │ String         │ 唯一订单编号（CS前缀+时间戳+UUID）│
    │ items    │ List<CartItem> │ 订单包含的商品列表              │
    │ total    │ double         │ 订单总金额                     │
    │ qrCodeUrl│ String         │ 模拟二维码支付链接               │
    │ status   │ String         │ 订单状态（"待支付"）             │
    └──────────┴────────────────┴──────────────────────────────┘
    在结算时由 checkout() 方法生成，其中 qrCodeUrl 供前端生成模拟二维码。

4.3  业务逻辑层 (service/)

    ShopService.java 使用 @Service 注解标记为 Spring Bean。
    内部使用两个 ArrayList 作为数据存储：
      - cakeList：蛋糕商品集合（服务启动时初始化，不可变）
      - cart：购物车条目集合（初始为空，随用户操作变化）

    (1) 商品初始化 —— @PostConstruct 注解的方法 initCakes()
        在 Spring Bean 实例化后自动执行，向 cakeList 中添加 8 款蛋糕：
        ┌────┬──────────────────┬────────┐
        │ ID │ 名称              │ 单价    │
        ├────┼──────────────────┼────────┤
        │ 1  │ 草莓奶油蛋糕       │ 128.00 │
        │ 2  │ 巧克力慕斯蛋糕     │ 158.00 │
        │ 3  │ 芒果千层蛋糕       │ 138.00 │
        │ 4  │ 提拉米苏           │ 108.00 │
        │ 5  │ 蓝莓芝士蛋糕       │ 148.00 │
        │ 6  │ 抹茶红豆蛋糕       │ 118.00 │
        │ 7  │ 黑森林蛋糕         │ 138.00 │
        │ 8  │ 红丝绒蛋糕         │ 168.00 │
        └────┴──────────────────┴────────┘

    (2) getAllCakes() —— 返回所有蛋糕列表，供首页浏览。

    (3) getCakeById(int id) —— 根据 ID 遍历 cakeList 查找指定蛋糕。

    (4) addToCart(int cakeId) —— 加入购物车逻辑：
        先通过 getCakeById 查找蛋糕，然后遍历 cart 列表：
        - 如果购物车中已有该蛋糕，则将其 quantity 加 1；
        - 如果没有，则创建新的 CartItem（数量为 1）加入 cart。

    (5) getCart() —— 返回当前购物车所有条目。

    (6) clearCart() —— 清空购物车列表。

    (7) checkout() —— 结算下单（本次新增）：
        首先检查购物车是否为空，为空返回 null。
        遍历 cart 列表，将每个 CartItem 深拷贝到新的 orderItems 列表中，
        防止后续清空购物车影响订单数据。同时累加计算 total。
        使用 System.currentTimeMillis() + UUID 生成唯一订单编号。
        构造 Order 对象返回，包含订单号、商品列表、总金额、二维码链接、
        订单状态（"待支付"）。

4.4  控制器层 (controller/)

    ShopController.java 使用 @RestController + @RequestMapping("/api")
    提供 RESTful 风格接口，所有响应均为 JSON 格式。

    API 接口一览：
    ┌────────┬─────────────────────┬──────────────────────────────────────┐
    │ 方法    │ 路径                 │ 功能说明                              │
    ├────────┼─────────────────────┼──────────────────────────────────────┤
    │ GET    │ /api/cakes          │ 获取全部蛋糕商品列表                    │
    │ POST   │ /api/cart/add       │ 添加商品到购物车（参数 cakeId）         │
    │ GET    │ /api/cart           │ 查看购物车（商品 + 总价）               │
    │ DELETE │ /api/cart/clear     │ 清空购物车                             │
    │ POST   │ /api/order/checkout │ 【新增】结算下单，返回订单及二维码链接    │
    │ POST   │ /api/pay/confirm    │ 【新增】确认支付，清空购物车             │
    └────────┴─────────────────────┴──────────────────────────────────────┘

    (1) GET /api/cakes
        直接调用 shopService.getAllCakes()，Spring MVC 自动将
        List<Cake> 序列化为 JSON 数组返回。响应示例：
        [
          { "id":1, "name":"草莓奶油蛋糕", "price":128.0, ... },
          { "id":2, "name":"巧克力慕斯蛋糕", "price":158.0, ... },
          ...
        ]

    (2) POST /api/cart/add?cakeId=1
        调用 shopService.addToCart(cakeId)，返回操作结果：
        {
          "success": true,
          "message": "已加入购物车",
          "cartCount": 2
        }
        cartCount 为当前购物车中不同商品的种类数。

    (3) GET /api/cart
        调用 shopService.getCart() 获取购物车列表，
        遍历计算总价 total，统一封装到 Map 中返回：
        {
          "items": [
            { "cake": {...}, "quantity": 2, "subtotal": 256.0 },
            ...
          ],
          "total": 394.0
        }

    (4) DELETE /api/cart/clear
        调用 shopService.clearCart() 清空购物车，返回成功消息。

    (5) POST /api/order/checkout —— 结算下单（新增）
        调用 shopService.checkout() 生成订单。若购物车为空返回错误提示；
        否则返回订单对象，含订单编号、商品列表、总金额、qrCodeUrl、状态。
        响应示例：
        {
          "success": true,
          "message": "订单已生成，请扫码支付",
          "order": {
            "orderId": "CS178074893034276BAE0",
            "items": [ { "cake": {...}, "quantity": 1, "subtotal": 128.0 } ],
            "total": 128.0,
            "qrCodeUrl": "/api/pay/qrcode?orderId=CS17...&amount=128.0",
            "status": "待支付"
          }
        }

    (6) POST /api/pay/confirm?orderId=xxx —— 确认支付（新增）
        调用 shopService.clearCart() 清空购物车，模拟支付成功。
        返回支付成功消息及订单号。

4.5  启动类 (CakeShopApplication.java)
    标准 Spring Boot 入口类，含 @SpringBootApplication 注解和 main 方法。

5.2  样式设计 (style.css)

    整体采用粉色系温馨风格：
    - 主色调：#FF6B6B（珊瑚粉），渐变背景
    - 卡片：白色圆角卡片 + 悬停上浮动效（transform + box-shadow）
    - 商品网格：CSS Grid 自适应布局，最小列宽 260px
    - 购物车面板：fixed 定位，初始 right: -420px，点击切换为 right: 0，
      配合 CSS transition 实现平滑滑入/滑出效果
    - Toast：fixed 定位 + transform translateY + opacity 过渡动效
    - 按钮：渐变背景 + hover 缩放 + active 按压缩放

    ----- 新增：支付弹窗样式 -----
    - 弹窗遮罩：fixed 定位全屏半透明黑色背景，flex 居中
    - 弹窗卡片：白色圆角，上滑淡入动画（@keyframes paySlideIn）
    - 二维码区域：Canvas 画布 180×180px，虚线边框
    - 去结算按钮：渐变粉底白字，独立于清空按钮展示
    - 确认支付按钮：绿色渐变，支付中禁用态灰色

5.3  交互逻辑 (app.js)

    核心流程：

    (1) 页面加载（DOMContentLoaded 事件）
        - 调用 loadProducts() 从 GET /api/cakes 获取商品列表
        - 调用 loadCart() 从 GET /api/cart 获取购物车状态（更新角标）

    (2) 浏览商品 —— loadProducts() + renderProducts()
        使用 fetch() 异步请求 /api/cakes，拿到 JSON 数组后，
        通过 Array.map() 拼接 HTML 模板字符串，一次性注入 productGrid。
        每个卡片包含：图片、名称、描述、单价、加入购物车按钮。

    (3) 加入购物车 —— addToCart(cakeId, button)
        发送 POST /api/cart/add?cakeId=xxx 请求。
        成功后：
        - 底部弹出 Toast 提示"已加入购物车"
        - 更新右上角购物车角标数字
        - 按钮临时变为绿色"✓ 已加入"状态，1.5 秒后恢复
        失败时弹出错误提示。

    (4) 查看购物车 —— toggleCart() + loadCart() + renderCart()
        点击右上角购物车按钮或遮罩层，切换 cartVisible 状态：
        - cartPanel 从右侧滑入/滑出
        - cartOverlay 遮罩层显示/隐藏
        面板打开时调用 loadCart() 获取最新购物车数据，
        renderCart() 动态渲染商品列表（图片、名称、单价、数量、小计）。
        购物车为空时显示空状态提示文字并隐藏底部结算栏。

    (5) 清空购物车 —— clearCart()
        发送 DELETE /api/cart/clear，成功后刷新购物车视图并弹出提示。

    (6) Toast 提示 —— showToast(message)
        底部居中弹出消息，2 秒后自动消失。
        使用 clearTimeout + setTimeout 实现防抖，快速连续操作不会叠加。

    ----- 新增：结算与支付流程 -----

    (7) 结算下单 —— checkout()
        用户点击购物车面板中"去结算"按钮触发。
        发送 POST /api/order/checkout 请求。
        成功后获取订单对象（orderId、total、items、qrCodeUrl）：
        - 将订单编号和金额填入弹窗的 payOrderId / payOrderAmount
        - 调用 drawQRCode(order) 在 Canvas 上绘制模拟二维码
        - 渲染订单商品清单到 payItems 区域
        - 显示支付弹窗

    (8) 模拟二维码生成 —— drawQRCode(order)
        使用 HTML5 Canvas API 在前端本地绘制二维码图案：
        - 绘制 200×200px 白色背景画布
        - 在三个角绘制二维码定位图案（层层嵌套的黑白方块）
        - 以订单号字符编码累加值为伪随机种子
        - 遍历网格，通过伪随机算法决定每个小格子是否填充黑色块
        - 跳过三个定位图案区域防止覆盖
        - 中心绘制白色底 + 红色"付"字图标

    (9) 确认支付 —— confirmPay()
        用户点击支付弹窗中"确认支付"按钮：
        - 按钮置灰显示"支付中..."，防止重复点击
        - 发送 POST /api/pay/confirm?orderId=xxx 请求
        - 后端清空购物车，返回成功消息
        - 前端按钮变绿显示"✓ 支付成功"
        - 1.5 秒后自动关闭弹窗，刷新购物车视图（显示为空）和角标
        - 底部弹出 Toast 提示支付成功

    (10) 关闭支付弹窗 —— closePayModal()
         点击弹窗关闭按钮或"取消"按钮时隐藏弹窗（移除 pay-overlay 的 active 类）

七、技术要点总结
--------------------------------------------------------------------------------
    1.  后端数据全存于内存（ArrayList），无数据库依赖，适合演示和学习。
    2.  前后端通过 RESTful JSON API 通信，完全分离。
    3.  前端零框架依赖，纯原生 JavaScript + Fetch API 实现。
    4.  购物车通过遍历匹配实现"同商品累加数量"逻辑。
    5.  使用 @PostConstruct 在服务启动时自动初始化商品数据。
    6.  CSS Grid + Flexbox 布局，适配不同屏幕宽度。
    7.  SVG 矢量图片替代网络图片，无需外网资源也可完整展示。
    8.  订单结算时对购物车数据做深拷贝，防止清空购物车后影响订单视图。
    9.  使用 Canvas API 在前端绘制模拟二维码图案（定位图案 + 伪随机数据块）。
    10. 订单编号采用时间戳 + UUID 组合，保证唯一性。
    11. 支付弹窗使用 CSS @keyframes 动画实现上滑淡入效果。
    12. 确认支付按钮支持防重复点击（disabled 态 + 文字提示）。
